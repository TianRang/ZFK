认证方式

所有 /api/v1/* 接口都需要 API Key。在「系统设置 → API 接口」创建 Key 后，通过下面任一方式传入：

  • 请求头 X-API-Key: zfk_xxxxx（推荐）
  • 请求头 Authorization: Bearer zfk_xxxxx
Base URL：{{ base_url }}
Key 仅在创建时显示一次，请妥善保管。被禁用或删除的 Key 立即失效。

错误响应

失败请求统一返回 { "detail": "错误描述" }，HTTP 状态码：

  • 400 参数错误
  • 401 缺少或无效的 API Key
  • 404 资源不存在
  • 409 资源冲突（如卡密已存在）

健康检查

GET/api/v1/ping

验证 API Key 是否有效。

curl -H "X-API-Key: zfk_xxxxx" {{ base_url }}/api/v1/ping
{ "ok": true, "message": "pong" }

卡密接口

查询卡密列表

GET/api/v1/cards

支持分页与筛选。Query 参数：

  • page 页码，默认 1
  • per_page 每页数量，默认 50，最大 200
  • key 按卡密内容模糊搜索（可选）
  • card_type 类型过滤：normal | points | shared_stock（可选）
curl -H "X-API-Key: zfk_xxxxx" \
  "{{ base_url }}/api/v1/cards?page=1&per_page=20&card_type=normal"
{
  "ok": true,
  "page": 1, "per_page": 20, "total": 128,
  "items": [
    {
      "id": 1, "key": "ABC123", "card_type": "normal",
      "content": "卡密内容", "description": "",
      "total_points": 0, "used_points": 0, "remaining": 0,
      "product_id": null,
      "created_at": "2026-05-23T10:00:00"
    }
  ]
}

查询单个卡密

GET/api/v1/cards/{id}
GET/api/v1/cards/by-key/{key}

按 ID 或卡密字符串查询单条。

curl -H "X-API-Key: zfk_xxxxx" \
  "{{ base_url }}/api/v1/cards/by-key/ABC123"

添加卡密

POST/api/v1/cards

请求体（JSON）：

  • key 字符串，必填，唯一
  • card_type 字符串，normal（默认） | points | shared_stock
  • content normal 时为单条内容；points 时为多行内容（每行一条额度）
  • description 可选说明
  • product_id shared_stock 必填，关联商品 ID
  • total_points shared_stock 必填，可提取额度

普通卡密：

curl -X POST {{ base_url }}/api/v1/cards \
  -H "X-API-Key: zfk_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "ABC123",
    "card_type": "normal",
    "content": "卡密对应的内容",
    "description": "VIP 30 天"
  }'

额度卡密（点数型）：

curl -X POST {{ base_url }}/api/v1/cards \
  -H "X-API-Key: zfk_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "POINTS-100",
    "card_type": "points",
    "content": "item-01\nitem-02\nitem-03"
  }'

共享库存卡密：

curl -X POST {{ base_url }}/api/v1/cards \
  -H "X-API-Key: zfk_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "SHARED-50",
    "card_type": "shared_stock",
    "product_id": 1,
    "total_points": 50,
    "description": "可提 50 次"
  }'

删除卡密

DELETE/api/v1/cards/{id}
DELETE/api/v1/cards/by-key/{key}
curl -X DELETE -H "X-API-Key: zfk_xxxxx" \
  {{ base_url }}/api/v1/cards/by-key/ABC123
{ "ok": true }

商品 / 库存接口

查询商品列表

GET/api/v1/products
curl -H "X-API-Key: zfk_xxxxx" {{ base_url }}/api/v1/products
{
  "ok": true,
  "items": [
    { "id": 1, "name": "商品A", "total_stock": 100, "used_stock": 12, "remaining": 88 }
  ]
}

查询单个商品

GET/api/v1/products/{id}

追加库存

POST/api/v1/products/{id}/stock

向已有商品追加库存（不会重置已用数）。请求体：

  • stock 字符串，多行；每行一条库存
curl -X POST {{ base_url }}/api/v1/products/1/stock \
  -H "X-API-Key: zfk_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{ "stock": "key-01\nkey-02\nkey-03" }'
{
  "ok": true, "added": 3,
  "product": { "id": 1, "name": "商品A", "total_stock": 103, "used_stock": 12, "remaining": 91 }
}
